29. Etiquetas, elementos y atributos

Las piezas de HTML · Negrita y cursiva

HTML utiliza etiquetas para marcar el contenido de una página. Los elementos son estructuras completas que incluyen una etiqueta de apertura, el contenido y una etiqueta de cierre. Los atributos agregan información adicional o configuración a las etiquetas.

¿Qué es una etiqueta?

Una marca que se escribe entre los signos < y > para indicar el tipo de contenido:

  • <p> … </p>: párrafo, indica un texto.
  • <h1> … </h1>: título, indica un encabezado de nivel 1.

Atributos frecuentes

Van dentro de la etiqueta de apertura. class e id los usamos en el TP11.

  • hrefLa dirección de un enlace<a href="…">
  • srcLa ruta de una imagen<img src="…">
  • altUn texto que describe la imagen<img alt="…">
  • classAgrupa estilos CSS<p class="…">
  • idUn identificador único<h2 id="…">

Negrita y cursiva

  • <strong> resalta un texto importante.
  • <em> enfatiza un texto.

Idea clave: una etiqueta indica el tipo de contenido, un elemento es la estructura completa y un atributo agrega datos adicionales o configuración.

30. Listas

ul, ol, li y listas anidadas

Una lista es un conjunto de elementos (ítems) que se muestran uno debajo del otro. Cada ítem va en un <li>.

  • Lista desordenada <ul>

    Con viñetas: el orden no importa.

  • Lista ordenada <ol>

    Con números: el orden sí importa.

Dato útil: listas anidadas

Una lista anidada va dentro de un ítem de otra lista. Sirve para organizar subelementos.

Idea clave: las listas sirven para organizar información en varios ítems y pueden ser ordenadas o no ordenadas.

31. Imágenes

img, src, alt, width, height y formatos

La etiqueta <img> inserta una imagen en la página: fotos, ilustraciones, logotipos y otros recursos visuales. Necesita la ruta del archivo y un texto alternativo que describa su contenido. Es un elemento vacío: no tiene etiqueta de cierre.

Atributos más usados

La estructura mínima es <img src="foto.jpg" alt="Paisaje">.

  • src (ruta de la imagen): indica la ubicación del archivo de imagen que se quiere mostrar.
  • alt (texto alternativo): describe el contenido de la imagen. Se muestra si la imagen no puede cargarse y mejora la accesibilidad.
  • width (ancho) y height (alto): definen el tamaño de la imagen, en píxeles.

Formatos comunes

  • JPG.jpg o .jpeg

    Ideal para fotografías. Buen equilibrio entre calidad y tamaño de archivo.

  • PNG.png

    Soporta transparencia y mantiene buena calidad. Muy usado en logotipos e ilustraciones.

  • SVG.svg

    Formato vectorial: se puede escalar sin perder calidad. Ideal para íconos y gráficos simples.

  • GIF.gif

    Permite imágenes animadas. Se usa para animaciones simples y elementos decorativos.

Idea clave: la etiqueta <img> permite mostrar imágenes y necesita información como su ruta y un texto alternativo.

32. Enlaces

a, href, target y title · Rutas

Los enlaces conectan páginas, archivos o secciones de una misma página. Se crean con la etiqueta <a>: el atributo href indica la dirección de destino y, entre las etiquetas, va el texto del enlace.

Atributos frecuentes

  • href: una URL, un archivo o una sección.
  • target="_blank": lo abre en una pestaña nueva.
  • title: texto de ayuda al pasar el cursor.

Tipos de enlaces y rutas

  • Externo: a otra página web en internet, con ruta absoluta: la dirección completa.
  • Interno: a otra página del mismo sitio, con ruta relativa, que se escribe desde la carpeta de la página: si el archivo está al lado, va su nombre; si está en una carpeta, la carpeta, una barra y el nombre.
  • A una sección de la misma página: #contacto lleva a la que tiene id="contacto".
  • De correo: abre el programa de correo del usuario.

Idea clave: los enlaces conectan páginas, archivos o secciones y permiten la navegación en la web.

Un poco más sobre cada lámina

Lámina 29

Etiqueta, elemento y atributo

  • Etiqueta: la marca que indica el tipo de contenido. Ej.: <p>.
  • Elemento: la estructura completa (etiqueta de apertura + contenido + etiqueta de cierre). Ej.: <p>Hola</p>.
  • Atributo: agrega información adicional o configuración a una etiqueta. Ej.: class="destacado".

Una etiqueta puede tener varios atributos, separados por un espacio, y cada valor va entre comillas: <img src="foto.jpg" alt="Paisaje">.

Elementos vacíos

No tienen contenido ni etiqueta de cierre: <img>, <br>, <hr> y <meta>. Todo lo que necesitan va en sus atributos.

Lámina 30

¿Cuándo usar cada una?

  • Usá <ul> cuando el orden no importa: para mostrar opciones o listar características, elementos o ideas.
  • Usá <ol> cuando el orden sí importa: para mostrar pasos o indicar un proceso o una secuencia.

Errores frecuentes

  • Escribir <li> sin un <ul> o un <ol> alrededor.
  • Poner la lista anidada después de </li>: va antes, dentro del ítem.
  • Olvidar el </ul> de la lista de afuera.

Lámina 31

Imágenes que cargan bien

En HTML, width y height van en píxeles, sin escribir px. Si ponemos solo uno, como en el ejemplo, el navegador calcula el otro para que la imagen no se deforme. Los porcentajes se dan con CSS (TP11).

Buenas prácticas

  • Usá el atributo alt siempre. Mejora la accesibilidad y ayuda a las personas que no pueden ver la imagen.
  • Optimizá el tamaño del archivo. Usá imágenes livianas para que la página cargue más rápido.
  • Usá nombres descriptivos, por ejemplo paisaje.jpg en lugar de img_123.jpg.

Lámina 32

Enlaces claros, rutas sin errores

Buenas prácticas

  • Usá textos descriptivos: “Ver precios” en lugar de “Hacé clic aquí”.
  • No abuses de “hacé clic aquí”: el texto tiene que describir el destino.
  • Revisá las rutas: que los archivos existan y estén bien escritos.
  • Usá target solo cuando tenga sentido, como en los enlaces externos.

Cuidado con las rutas

  • Va siempre la barra /, aunque Windows muestre \.
  • En internet, Foto.JPG y foto.jpg son archivos distintos.
  • Nombres sin espacios ni acentos.
