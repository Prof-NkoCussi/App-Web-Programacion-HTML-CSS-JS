5. Comparar y combinar

Operadores de comparación y lógicos

Una comparación responde con un booleano: true (verdadero) o false (falso). Con esas respuestas, el programa toma decisiones.

  • ===Igual
  • !==Distinto
  • <Menor
  • >Mayor
  • <=Menor o igual
  • >=Mayor o igual

  • && (y)

    Da true si las dos condiciones son verdaderas.

  • || (o)

    Da true si al menos una es verdadera.

  • ! (no)

    Invierte el resultado: !true da false.

6. Tomar decisiones

if, else if y else

if ejecuta un bloque solo si la condición da true. else if prueba otra condición y else va si no se cumple ninguna. Se ejecuta un solo bloque: el primero que cumple.

  1. 1La condición va entre paréntesis: if (nota >= 6)
  2. 2El bloque va entre llaves { }, sin :
  3. 3elif se escribe else if, en dos palabras.

7. Repetir mientras se cumpla

while y do...while

Un bucle repite un bloque de código. Algo dentro del bloque tiene que cambiar la condición; si no, el bucle no termina nunca.

  • while

    Pregunta antes de cada vuelta. Si la condición da false de entrada, no se ejecuta nunca.

  • do...while

    Pregunta después de cada vuelta: se ejecuta al menos una vez. Sirve para pedir un dato hasta que esté bien.

8. El bucle for

Contadores y acumuladores

Usamos for cuando sabemos cuántas vueltas va a dar el bucle. Entre los paréntesis van tres partes, separadas por punto y coma.

  • Inicio

    let i = 1

    Se hace una sola vez, antes de la primera vuelta.

  • Condición

    i <= 5

    Se revisa antes de cada vuelta. Con false, termina.

  • Paso

    i++

    Se hace al final de cada vuelta. i++ es i = i + 1.

  • Contador

    Suma 1 cada vez: pares = pares + 1;

  • Acumulador

    Suma un valor: suma = suma + i;

Consola · salida esperada
Suma: 55
Pares: 5

En Python → En JavaScript

Idea clave: for junta en una línea el inicio, la condición y el paso. Los contadores y acumuladores empiezan en 0, antes del bucle.

Un poco más sobre cada lámina

Lámina 5

¿Por qué === y no ==?

JavaScript también tiene == y !=, pero antes de comparar convierten los datos al mismo tipo: para ==, el número 5 y el texto "5" son iguales. === y !== comparan el valor y el tipo. Por eso usamos siempre estos dos.

Para recordar

  • 5 == "5" → true · 5 === "5" → false
  • true && false → false · true || false → true
  • !(5 > 3) → false
  • En Python vale 13 <= edad <= 17. En JavaScript se escribe edad >= 13 && edad <= 17

Lámina 6

Errores frecuentes con if

Para que el código se lea fácil, dejamos sangría dentro de cada bloque y combinamos condiciones con && y || en lugar de poner un if dentro de otro. En VS Code, Shift + Alt + F acomoda la sangría sola.

Cuidado con

  • if (nota = 10) guarda 10 en nota en vez de comparar. Va ===.
  • if (nota >= 6); con punto y coma: el bloque se ejecuta siempre. Después de ) y de } no va ;
  • elif no existe en JavaScript: da error.

Lámina 7

Lámina 8

Atajos y qué bucle elegir

i++ suma 1 e i-- resta 1. suma += n es lo mismo que suma = suma + n. Para contar hacia atrás: for (let i = 10; i >= 1; i--)

¿Qué bucle uso?

  • for: sabemos cuántas vueltas va a dar.
  • while: repetimos mientras se cumpla una condición, sin saber cuántas vueltas.
  • do...while: el bloque tiene que ejecutarse al menos una vez.
