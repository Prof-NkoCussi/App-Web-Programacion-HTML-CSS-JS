37. ¿Qué es CSS?

La regla, los selectores y la etiqueta style

CSS (Cascading Style Sheets) es el lenguaje que define la apariencia visual de una página web. Permite darle estilo: cambiar colores, definir tipografías, ajustar espaciados, establecer tamaños y crear diseños atractivos y coherentes.

  • Selector: indica a qué elemento se aplica el estilo.
  • Propiedad: define qué característica se va a modificar.
  • Valor: es el valor que toma la propiedad (puede ser un color, un tamaño, etc.).

Tipos de selectores

El selector es la parte de la regla que indica qué elementos del HTML reciben el estilo.

  • h1 Selector de etiqueta: selecciona todos los elementos de ese tipo de etiqueta.
  • * Selector universal: selecciona todos los elementos de la página.

Los selectores de clase y de id los vemos en el TP11.

Cómo se conecta con HTML

Mediante la etiqueta <style>, en el encabezado de la página (<head>). Adentro van las reglas CSS que el navegador aplica a la página.

En el TP11 pasamos el CSS a un archivo aparte.

Idea clave: CSS define la apariencia visual de HTML. Sus reglas van dentro de <style>, en el <head>, y los selectores eligen qué elementos reciben cada estilo.

38. Colores y fondos

color, background-color y formatos de color

CSS permite cambiar el color del texto y el fondo de los elementos y páginas. Con estas propiedades podemos darle estilo, destacar información importante y crear una identidad visual para nuestro sitio web.

Propiedades principales

  • color define el color del texto de un elemento: color: #2563eb;
  • background-color define el color de fondo de un elemento: background-color: #f3f4f6;

Formatos de color

  • Nombres de coloresroyalblue
  • Código hexadecimal#2563eb
  • Función rgb()rgb(236, 72, 153)
  • Función rgba()rgba(37, 99, 235, 0.7)

Idea clave: CSS puede definir colores de texto, colores de fondo e imágenes de fondo, ayudando a crear jerarquía visual y una identidad para la página web.

39. Tipografías y texto

La letra, el tamaño, el grosor y la alineación

La tipografía es un elemento fundamental en el diseño web, ya que influye en la legibilidad y en la experiencia del usuario. CSS ofrece diversas propiedades para mejorar la presentación visual del texto y hacer que el contenido sea más claro y atractivo.

  • font-family

    Define el tipo de letra que se utiliza.

    font-family: Arial,
    sans-serif;
  • font-size

    Establece el tamaño del texto.

    font-size: 20px;
  • font-weight

    Define el grosor del texto (normal, negrita, etc.).

    font-weight: bold;
  • text-align

    Determina la alineación del texto (izquierda, centro, derecha, etc.).

    text-align: center;
  • line-height

    Controla el espacio entre líneas de texto.

    line-height: 1.5;
  • color

    Define el color del texto.

    color: #2563eb;

Idea clave: CSS controla cómo se ve el texto en una página web: el tipo de letra, el tamaño, el grosor, la alineación, el espaciado y mucho más.

40. Margin y padding

Espacio externo y espacio interno

En CSS, el padding es el espacio interno entre el contenido y el borde, mientras que el margin es el espacio externo entre un elemento y otros elementos. Ambos ayudan a organizar el contenido y mejorar el diseño visual de una página web.

  • ¿Qué es el padding?

    El padding es el espacio interno entre el contenido y el borde del elemento. Permite que el contenido no quede pegado al borde.

    padding: 20px;

  • ¿Qué es el margin?

    El margin es el espacio externo fuera del borde del elemento, que lo separa de otros elementos. Se utiliza para crear distancia entre elementos.

    margin: 20px;

Buenas prácticas: usá padding para dar aire al contenido y margin para separar elementos. Mantené un espaciado consistente en toda la página.

Idea clave: el padding agrega espaciado interno (dentro del borde) y el margin agrega espaciado externo (fuera del borde). Ambos ayudan a organizar y mejorar el diseño.

Un poco más sobre cada lámina

Lámina 37

Un CSS ordenado

Una regla puede ir en una sola línea, como en la lámina 37, o en varias, como en la 38: el navegador la lee igual. Con varias propiedades, conviene escribir una por línea.

Los comentarios de CSS van entre /* y */: /* Títulos */. El // de JavaScript no sirve en CSS: rompe la regla que sigue.

Resumen rápido: HTML es el contenido (estructura y significado) y CSS, la apariencia (diseño y estilo). Ambos trabajan juntos para crear páginas web completas.

Buenas prácticas: mantené tu CSS organizado. Agrupá y comentá tus estilos para que sea más fácil de leer y modificar.

Lámina 38

Más sobre colores y fondos

  • royalblue: un nombre predefinido en inglés.
  • #2563eb: el formato más utilizado. Tres pares de cifras, de 00 a ff: rojo, verde y azul.
  • rgb(37, 99, 235): el mismo azul, de 0 a 255.
  • rgba(37, 99, 235, 0.7): el mismo azul, al 70 %. El último valor, alpha, va de 0 a 1.

background-image: url("paisaje.svg"); pone una imagen de fondo. Con background-repeat: no-repeat;, se ve una sola vez.

opacity: 0.8; define la transparencia de todo el elemento, también la de su texto: va de 0 a 1.

Buenas prácticas: mantener un buen contraste entre el texto y el fondo, no abusar de la cantidad de colores y usar una paleta coherente en todo el sitio.

Lámina 39

La lista de fuentes de respaldo

font-family: "Segoe UI", Arial, sans-serif; es una lista: el navegador usa la primera fuente que tenga la computadora. Si no está Segoe UI, prueba con Arial, y si tampoco, usa cualquier fuente sin serifa.

Los nombres con espacios van entre comillas. Al final va siempre una familia genérica: sans-serif (sin serifa, como Arial, Verdana o Segoe UI) o serif (con serifa, como Georgia). Esas cuatro fuentes ya vienen en Windows.

font-weight también acepta números del 100 al 900: 400 es normal y 700, negrita.

Buenas prácticas: no uses demasiadas fuentes (con una o dos es suficiente), mantené una buena jerarquía con distintos tamaños y grosores, cuidá el contraste y usá tamaños legibles.

Lámina 40

Un lado por vez

  • Un valor: el mismo espacio en los cuatro lados: margin: 20px;
  • Dos valores: el primero es arriba y abajo; el segundo, a los costados: padding: 10px 20px;
  • Un solo lado: se agrega -top (arriba), -right (derecha), -bottom (abajo) o -left (izquierda): margin-bottom: 16px;

El navegador ya les pone margin a body, a los títulos y a los párrafos: por eso la página no empieza pegada al borde de la ventana. Con margin: 0; se lo sacamos.
