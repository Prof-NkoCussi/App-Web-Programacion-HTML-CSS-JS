1. Hola, JavaScript

Programar en el navegador

JavaScript es un lenguaje de programación, como Python. Sus programas corren en el navegador (Chrome, por ejemplo), sin instalar nada más.

La carpeta plantilla

plantilla-js

  • index.htmlYa está armado. Lo abrimos en Chrome, pero no lo tocamos.
  • app.jsEmpieza vacío. Acá escribimos el programa.

Descargar la plantilla (.zip) Antes de usarla, la extraemos: clic derecho sobre el .zip → Extraer todo…

Cómo trabajamos

  1. 1VS Code

    En Visual Studio Code, Archivo → Abrir carpeta… y elegimos la carpeta. Escribimos en app.js.

  2. 2Chrome

    En el Explorador de archivos, clic derecho sobre index.html → Abrir con → Google Chrome.

  3. 3La consola

    En Chrome tocamos F12 y elegimos la pestaña Console. Ahí vemos lo que muestra el programa.

  4. 4Cada cambio

    Guardamos con Ctrl + S en VS Code y recargamos con F5 en Chrome.

En Python → En JavaScript

Idea clave: escribimos el programa en app.js con VS Code y vemos el resultado en la consola de Chrome.

2. Mostrar mensajes

console.log(), alert() y comentarios

  • console.log()

    Escribe en la consola. La usamos para ver resultados y probar el programa.

  • alert()

    Abre una ventana con un mensaje. El programa espera hasta que tocamos Aceptar.

Consola · salida esperada
Hola, JavaScript
Estoy en la escuela
10
alert: ¡Bienvenidos!
Fin del programa

Reglas para escribir

  1. 1Cada instrucción termina con punto y coma: ;
  2. 2Los textos van entre comillas: "Hola". Los números, no: 7.
  3. 3Lo que sigue a // es un comentario: el programa lo saltea. Sirve para explicar el código.
  4. 4Las mayúsculas importan: Console.log da error.

En Python → En JavaScript

Idea clave: console.log() muestra en la consola y alert(), en una ventana. Cada instrucción termina con ;

3. Variables y tipos de datos

let, const y typeof

  • Variable

    Guarda un dato con un nombre, como en Python. La primera vez, la creamos con let o const.

  • let

    Para datos que cambian. Después se cambian sin let: puntos = 10;

  • const

    Para datos que no cambian: const dias = 7; Si lo cambiamos, da error.

  • Número

    42 · 3.5

    Enteros y decimales. El decimal va con punto.

    typeof → "number"

  • Texto

    "Hola"

    Letras, números o signos entre comillas.

    typeof → "string"

  • Booleano

    true · false

    Solo dos valores: verdadero o falso.

    typeof → "boolean"

Consola · salida esperada
Lucía 17 Ushuaia
string
number
boolean

En Python → En JavaScript

Idea clave: let para lo que cambia y const para lo que no. typeof nos dice de qué tipo es un dato.

4. Pedir datos y hacer cuentas

prompt(), Number() y operaciones

prompt() abre una ventana con una pregunta y un casillero. Lo que escribe el usuario llega siempre como texto.

  • +Suma

    7 + 2 → 9

  • -Resta

    7 - 2 → 5

  • *Multiplicación

    7 * 2 → 14

  • /División

    7 / 2 → 3.5

  • %Resto

    7 % 2 → 1

Error controlado: 5 + 3 da 53

Así falla

Consola · salida esperada

Con 5 y 3:

53

Así se corrige

Consola · salida esperada

Con 5 y 3:

8

Qué pasó: prompt() devuelve texto: "5" y "3". Entre dos textos, + no suma: los une. Cómo se corrige: Number() convierte el texto en número, y ahora + suma.

En Python → En JavaScript

Idea clave: prompt() siempre devuelve texto. Para hacer cuentas, lo pasamos a número con Number(), que reemplaza a int() y float().

+ Para profundizar

Un poco más sobre cada lámina

Lámina 1

Extraer y comprimir la carpeta

La plantilla se descarga como un archivo .zip: una carpeta comprimida en un solo archivo. Antes de usarla, la extraemos: clic derecho sobre el .zip → Extraer todo… → Extraer.

Para entregar hacemos lo contrario: comprimimos nuestra carpeta en un .zip y lo subimos a Classroom.

Comprimir en .zip (Windows)

  1. En el Explorador de archivos, clic derecho sobre la carpeta.
  2. En Windows 10: Enviar a → Carpeta comprimida (en zip). En Windows 11: Comprimir en archivo ZIP.
  3. Aparece un archivo .zip con el mismo nombre. Ese es el que subimos.

Lámina 2

Cuando algo falla

Si hay un error, la consola lo muestra en rojo, con el archivo y la línea (por ejemplo, app.js:2). El programa se detiene en esa línea.

Consola · salida esperada
Uno
Uncaught ReferenceError: Console is not defined

Errores frecuentes

  • console.log(Hola); Faltan las comillas: Hola is not defined.
  • console.log("Hola"; Falta cerrar el paréntesis: missing ) after argument list.

Lámina 3

Nombres de variables

Un buen nombre dice qué guarda la variable: edad, precioFinal. Si tiene dos o más palabras, usamos camelCase: todo junto y cada palabra nueva con mayúscula.

Cambiar una const da error: Assignment to constant variable.

Reglas

  • Sin espacios ni guiones, y sin empezar con un número: nota final, nota-final y 1nota dan error.
  • No podemos usar palabras de JavaScript, como let o const.
  • nota y Nota son dos variables distintas.

Lámina 4

Más sobre números

Si Number() recibe algo que no es un número, devuelve NaN (Not a Number: "no es un número"). Pasa, por ejemplo, si escribimos el decimal con coma.

Como en matemática, primero se hacen * y /, y después + y -. Los paréntesis cambian el orden.

Ejemplos

  • Number("3.5") → 3.5 · Number("3,5") → NaN
  • Number("hola") → NaN
  • 2 + 3 * 4 → 14 · (2 + 3) * 4 → 20
  • Promedio de tres notas: (n1 + n2 + n3) / 3
