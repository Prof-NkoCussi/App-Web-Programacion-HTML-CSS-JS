25. HTML + CSS + JavaScript

Cómo trabajan juntos

Una página web se construye con tres tecnologías que trabajan en conjunto. Cada una tiene un rol específico:

  • HTML Estructura

    HTML (HyperText Markup Language) crea la estructura de la página. Define el contenido y su organización: títulos, párrafos, imágenes, enlaces, formularios.

  • CSS Diseño

    CSS (Cascading Style Sheets) da estilo y diseño a la página. Controla colores, tipografías, tamaños, espaciados, posiciones y mucho más.

  • JavaScript Interactividad

    El lenguaje que usamos desde el TP1. En la página, responde a acciones del usuario, modifica el contenido, valida formularios y muestra mensajes.

Idea clave: la estructura (HTML), el diseño (CSS) y la interactividad (JavaScript) se complementan para crear páginas web completas.

26. El entorno de trabajo

Archivos .html, .css y .js

Antes de crear páginas web, necesitamos un entorno de trabajo simple y organizado. Es el mismo que usamos desde el TP1. Lo nuevo: ahora creamos los archivos desde cero.

Elementos del entorno

  • Editor: para escribir HTML, CSS y JavaScript.
  • Navegador: para ver y probar la página. También sirven Firefox o Edge.
  • Carpeta: guarda los archivos del sitio.
  • Extensiones (opcionales): Live Server y Prettier.

Paso a paso

  1. 1Crear la carpeta

    Clic derecho → Nuevo → Carpeta. La llamamos mi-sitio.

  2. 2Abrirla en el editor

    En VS Code: Archivo → Abrir carpeta…

  3. 3Crear los archivos

    En el panel de VS Code, clic derecho → Nuevo archivo… y el nombre con su extensión.

  4. 4Probar en el navegador

    Abrimos index.html con Chrome. Con cada cambio: Ctrl + S y F5.

Cómo se conectan

  • Los tres archivos se guardan en la misma carpeta y se vinculan desde index.html.
  • Archivo .html = contenido. Archivo .css = apariencia. Archivo .js = comportamiento.
  • <script> lo vemos en la lámina 27 y <link>, en el TP11.

Idea clave: para empezar a desarrollar necesitamos un editor de código, un navegador web y una carpeta ordenada para guardar los archivos.

27. Estructura básica de HTML

La plantilla del TP1, línea por línea

Qué hace cada línea

  • <!DOCTYPE html>: es un documento HTML5. Va primero.
  • <html lang="es-AR"> contiene todo. lang es el idioma: español de Argentina.
  • <head>: datos que no se ven. En las dos <meta>, charset hace que se vean bien los acentos y la ñ, y viewport, que la página se adapte al celular. <title> es el título de la pestaña.
  • <body>: el contenido visible. <h1> es un título y <p>, un párrafo (lámina 28). <strong> resalta un texto (TP8).
  • <script src="app.js"> carga y ejecuta app.js: por eso nuestros programas corren al abrir la página.
  • </head>, </body>, </html> cierran lo que se abrió, con /.

Idea clave: todo documento HTML parte de una estructura base, con doctype, html, head y body, que el navegador usa para mostrar la página.

28. Títulos y párrafos

De h1 a h6, p, br y hr

Los títulos y los párrafos nos permiten organizar y presentar la información de una página web. Los títulos van del <h1>, el más importante, al <h6>, el de menor jerarquía.

Importante

Usá un solo <h1> por página y mantené el orden de jerarquía (h1, h2, h3…) para una mejor estructura.

  • Párrafo <p>

    Define un párrafo de texto, con espacio arriba y abajo.

  • Salto <br>

    Corta la línea dentro de un texto. No se cierra.

  • Línea <hr>

    Separa dos partes con una línea. No se cierra.

Idea clave: los títulos organizan la información y los párrafos desarrollan el contenido. <br> corta una línea y <hr> separa dos partes.

Lámina 25

Cómo funciona una página web

Una página web es un conjunto de archivos que un servidor envía a nuestro navegador, que los interpreta y los muestra.

  1. Escribimos la dirección de la página.
  2. El navegador se la pide al servidor.
  3. El servidor envía el HTML, el CSS y el JS.
  4. El navegador interpreta los archivos.
  5. Se muestra la página y podemos usarla.

Mientras trabajamos no hace falta servidor: el navegador abre los archivos desde la carpeta.

Lámina 26

Buenas prácticas iniciales

Desde el primer día

  • Nombres simples, sin espacios: mi-sitio.
  • Guardar seguido: Ctrl + S.
  • Archivos ordenados: las imágenes, aparte.
  • Probar los cambios: F5 en el navegador.

Extensiones de VS Code (opcionales)

  • Instalar: Ctrl + Shift + X, buscar el nombre e Instalar.
  • Live Server: clic derecho sobre index.html → Open with Live Server. Al guardar, la página se recarga sola.
  • Prettier: Shift + Alt + F ordena el código.

Lámina 27

La estructura, en un segundo

Todo lo que está dentro de <body> es lo que el usuario ve en la página. El contenido del <head> no se muestra directamente.

Las etiquetas se cierran en orden inverso: lo último que se abrió es lo primero que se cierra. Por eso </body> va antes que </html>.

Atajo de VS Code

  1. En un index.html vacío, escribimos ! y tocamos Enter.
  2. Aparece la estructura básica completa.
  3. Cambiamos lang="en" por lang="es-AR" y Document por el título de nuestra página.

Lámina 28

Los espacios de más no cuentan

El navegador junta los espacios y Enter de más en uno solo. Para cortar una línea, va <br>.

Recomendación: escribí textos claros y breves para que tu página sea más fácil de leer.
