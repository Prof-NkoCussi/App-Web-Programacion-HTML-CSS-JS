21. ¿Qué es un objeto?

Los datos de una misma cosa, cada uno con su nombre

Un objeto guarda en una sola variable los datos de una misma cosa: un producto del kiosco, un alumno, un celular. Cada dato es una propiedad, con un nombre y un valor.

  • Array

    Guarda muchos datos del mismo tipo, en orden: los precios de todo el kiosco. Cada dato tiene una posición.

  • Objeto

    Guarda los datos distintos de una sola cosa: el nombre, el precio y si hay stock de un alfajor. Cada dato tiene un nombre.

Cómo se escribe

  • Las propiedades van entre llaves { }.
  • Cada una lleva nombre, dos puntos y valor: precio: 800.
  • Entre una propiedad y la siguiente va una coma.
  • El valor puede ser un número, un texto o un booleano. El nombre va en camelCase: hayStock.
Consola · salida esperada
{nombre: "Alfajor", precio: 800, hayStock: true}

Idea clave: el array guarda muchos datos del mismo tipo, cada uno en una posición. El objeto guarda los datos de una sola cosa, cada uno con su nombre.

22. Leer y modificar propiedades

Con un punto: objeto.propiedad

  • Leer

    Nombre del objeto, un punto y la propiedad: alfajor.precio da 800. Si la propiedad no existe, da undefined.

  • Modificar

    Con = le damos un valor nuevo: alfajor.precio = 900; El valor anterior se pierde. Si la propiedad no existía, se agrega.

Consola · salida esperada
Alfajor: $800
{nombre: "Alfajor", precio: 900, stock: 11, sabor: "chocolate"}
undefined

¿Qué pasó?

  • precio pasó de 800 a 900: el 800 se perdió.
  • stock usó su propio valor: 12 − 1 = 11, como un acumulador.
  • sabor no existía: se agregó al final.
  • marca no existe: leerla da undefined (sin valor).

Idea clave: con un punto leemos una propiedad: alfajor.precio. Con = la cambiamos. Si no existe, leerla da undefined y darle un valor la agrega.

23. Arrays de objetos

Una lista de cosas, cada una con sus datos

En un array de objetos, cada dato de la lista es un objeto. Sirve para guardar muchas cosas del mismo tipo, cada una con sus propiedades: los alumnos de un curso, los productos del kiosco.

Primero la posición, después la propiedad

  • alumnos[1] es el objeto de la posición 1: el de Tomás.
  • alumnos[1].nota es la nota de ese objeto: 5.
  • alumnos.length cuenta los objetos: 3.
Consola · salida esperada
{nombre: "Tomás", nota: 5}
5
4
Sofía aprobó
Lucía aprobó
  1. 1En el for...of, alumno toma un objeto por vuelta. push agrega un objeto entero.
  2. 2Todos los objetos tienen las mismas propiedades: el mismo código sirve para todos.

Idea clave: en un array de objetos, primero va la posición y después la propiedad: alumnos[1].nota. Con for...of, cada vuelta trae un objeto entero.
